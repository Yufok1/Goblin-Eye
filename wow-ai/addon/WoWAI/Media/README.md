Goblin Eye emblem

Original transparent artwork generated for this project using OpenAI image
generation on October 5, 2026. It is offered under the project's MIT license.
No extracted Blizzard character artwork is included.

GoblinEye.tga is a 256 x 256, 32-bit, uncompressed TGA with an alpha channel.
GoblinEye.png is the matching portable preview. Lua supplies the glow and unread
badge; they are not baked into the image. No texture animation timer is required.
