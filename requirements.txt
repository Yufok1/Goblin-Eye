# Goblin Eye has no third-party Python runtime dependencies.
#
# The Windows ZIP bundles its own pinned Python interpreter in python/, so a
# player never installs Python. Running
# `python -m pip install -r requirements.txt` is valid and installs nothing.
#
# Optional editable developer install: `python -m pip install -e .`
# That developer install uses the build requirements declared in pyproject.toml.
#
# Node.js/npm are needed only to rebuild the web UI, not to run the ZIP.
# Your CLI agent is installed and authenticated separately; it is not a Python
# dependency of Goblin Eye, and no model provider API key is required by this app.
